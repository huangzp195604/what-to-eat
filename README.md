# 知味 · 等会吃什么 (What to Eat)

这是一个单文件完整打包的纯前端网页，已内置全部中国风视觉设计、传统水墨插图、音效合成与餐厅雷达交互算法。

## 本地打开与使用方法

### 方式 1：直接双击打开（最推荐）
直接双击 `what_to_eat.html`（或双击「双击直接打开.bat」），即可自动使用您的电脑默认浏览器打开运行，无需启动任何服务！

### 方式 2：使用 8000 端口本地服务
如果您需要在本地服务器运行：
1. 在本文件夹空白处打开终端 / 命令行（Terminal 或 CMD）
2. 执行以下命令启动服务：
   python -m http.server 8000
   （如果使用 python3，请输入：python3 -m http.server 8000）
3. 在谷歌浏览器中访问：
   http://localhost:8000/what_to_eat.html

## 注意事项

- **高德地图 API Key**：本项目的餐厅雷达功能依赖高德地图 Web 服务，页面内已内置一个 Key。请在高德开放平台控制台为该 Key 配置 **Referer 白名单**（本地开发填 `localhost`；部署上线后追加线上域名），避免被他人盗用产生费用。
- **首次加载较慢**：页面会从 CDN 加载 Tailwind CSS 与 Google Fonts，国内网络下字体可能降级为系统字体，属正常现象，不影响功能。
- **音效**：背景音乐 `bgm.mp3` 需与 `what_to_eat.html` 放在同一目录下；浏览器可能因自动播放策略要求先点击页面一次才会播放。
